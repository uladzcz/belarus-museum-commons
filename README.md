# Асістэнт загрузкі музейных экспанатаў Беларусі ў Вікісховішча і Вікіданыя

Інтэрактыўны каталог-абгортка Дзяржаўнага каталога Музейнага фонду Рэспублікі Беларусь ([dkmf.by](https://dkmf.by)) з падтрымкай правіла **PD-Art** (*Bridgeman Art Library v. Corel Corp.*), аўтаматычнай праверкай аўтарскага права (Беларусь і ЗША), падтрымкай шматвыяўных экспанатаў і генерацыяй 9-моўных апісанняў праз **Google Gemini AI**.

---

## 🌟 Асноўныя магчымасці

1. **Інтэрактыўны каталог і фільтрацыя**:
   - Хуткі жывы пошук па назвах, перыядзе стварэння, музеях, матэрыялах і тэхналогіях.
   - Фільтрацыя па ліцэнзійным статусе Вікісховішча:
     - 🟢 **Толькі 2D Грамадскі набытак (PD-Art)**: створаныя да 1929 года або безумоўны гістарычны перыяд.
     - ⚠️ **2D на свой страх і рызыку**: творы, створаныя да 1956 года (больш за 71 год таму), але пазней за 1928 год (патрабуюць удакладнення даты смерці аўтара).
     - ⛔ **2D Загрузка забароненая**: творы, створаныя менш чым 71 год таму (пасля 1955 года) — ахоўваюцца аўтарскім правам.
     - 📦 **3D-аб'екты**: крэслы, скульптура, посуд, зброя і інш. (паводле правіл Вікісховішча фатограф мае асобнае аўтарскае права).
   - Фільтрацыя па наяўнасці сувязі з Вікіданымі (звязаныя / яшчэ няма).

2. **Падтрымка шматвыяўных экспанатаў**:
   - Для манет (аверс / рэверс), шматстаронкавых дакументаў і лістоў даступная зручная галерэя з мініяцюрамі і стрэлкамі.
   - Спампоўка і загрузка ў Вікісховішча ажыццяўляюцца паасобку для кожнай выявы з аўтаматычнай нумарацыяй файла: ... (1).jpg, ... (2).jpg.

3. **Фармат назваў файлаў для Вікісховішча**:
   - Без згадкі каталога: {Музей}. {Назва}, {Перыяд}, {Краіна/Месца}, {Аўтары} [(N)].jpg.

4. **Інтэграцыя з Google Gemini AI**:
   - Выкарыстанне хуткай актуальнай мадэлі gemini-3.6-flash.
   - Ключ API уводзіцца карыстальнікам і захоўваецца **выключна лакальна** ў браўзеры (localStorage).
   - У адзін клік фармуе:
     - Назву файла з годам.
     - Поўны шаблон {{Artwork}} на **9 мовах**: e, en, r, de, es, it, pl, lt, 
u.
     - Беларускую лацінку для тапонімаў (напрыклад, *Viliejka*, *Polack*).
     - Шаблоны {{Size}}, {{Technique}}, {{Institution}} і адпаведныя катэгорыі Вікісховішча.
     - Падстаўляе гатовы вікітэкст у форму загрузкі Special:Upload.

5. **Звязвальнік з Вікіданымі (Wikidata)**:
   - Прамы пошук дублікатаў і кнопка стварэння новага элемента праз Special:NewItem.
   - Генерацыя і капіяванне каманд для інструмента **QuickStatements**.
   - Лакальнае захаванне прывязкі QID у браўзеры з магчымасцю экспарту і імпарту базы сувязяў у JSON.

## 🚀 Як апублікаваць на GitHub Pages

Праект цалкам аўтаномны (статычны HTML + CSS + JS без неабходнасці сервера або баз даных).

1. Стварыце новы рэпазіторый на [GitHub](https://github.com/new) (напрыклад, elarus-museum-commons).
2. Загрузіце ў яго файлы: index.html, README.md, .nojekyll.
3. Адкрыйце ў рэпазіторыі: **Settings** → **Pages** → **Build and deployment**:
   - **Source**: Deploy from a branch
   - **Branch**: main (тэчка / (root))
   - Націсніце **Save**.
4. Праз 1-2 хвіліны ваш сайт будзе даступны па адрасе:
   https://<ваш_нікнейм>.github.io/belarus-museum-commons/
